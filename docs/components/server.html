Process Architecture

Request Lifecycle

POST /v1/chat/completionsentry
FrontendHandler.do_POST() parses the JSON body via ThreadingHTTPServer.
1 · Normalize shapeapi_shapes.py
OpenAI, Anthropic, or Responses shape → canonical messages. Handles anthropic_to_chat_body(), anthropic_to_chat_prompt().
2 · Prepare for generationfrontend.py
  • Jinja2 chat template → token ids
  • thinking.py: extract / encode thinking level
  • tool_schema.py: build tool-call grammar (CFG)
  • images.py: resize images, compute patch grids
  • constraints.py: validate tokenizer, build constraint factory
3 · Submit to backendbackend.py
NativeBackend.submit() assigns priority, deadline, and writes the request frame to the pipe via runtime.py.
4 · Stream tokens backruntime.py → SSE
Reader thread receives Tokens frames → output.py decodes → SSE chunks written to the HTTP response. Done frame closes the stream.
5 · Mask round-trip (tool calls)protocol.py
Engine sends MaskRequest → Python builds CFG token mask → sends MaskResponse → engine resumes decode.

Key Design Decisions

Subprocess, not thread
The native engine runs as a child process connected via stdin/stdout pipes. A crash in Metal/C++ doesn't take down the Python HTTP server. The reader thread in runtime.py multiplexes frames.
Binary protocol, not JSON
The pipe uses a 24-byte binary frame header (magic SPLH, version 5) with typed payloads. This avoids JSON parse overhead on every token. Python protocol.py and C++ Protocol.cpp are mirror images.
CPU grammar masks
Constraint masks (tool-call JSON grammar) are computed on the Python CPU via constraints.py. The engine pauses in WaitingMask phase until the mask arrives. This keeps the GPU free for inference.
Graceful shutdown
SIGTERM → backend.close() → child gets shutdown frame → grace period → SIGKILL. Reader thread joined with 1s timeout. Signal handlers set to SIG_IGN during teardown.

Threading Model

Key invariant: Callbacks from the reader thread must return quickly. Blocking callers use RuntimeCall.result on their own thread. The reader thread never blocks on mask computation or image processing — those happen on request threads.
