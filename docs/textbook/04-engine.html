Batch Packing

Prefill
  • Packs the shortest remaining sequences first into an actual-row budget
  • A bound on how often later arrivals may overtake a lane
  • Rows per command = prefillChunkTokens (package-chosen, ≤ built max)
Decode
  • Dispatches every ready lane immediately
  • Only four real shapes: M8 / M16 / M24 / M32
  • maximumBatchWidth = 4 lanes
  • Each lane = one request's decode step

Caches composite recurrent states (GDN cells, etc.). CompositeStateLease: move-only handle to a cached state at a boundary. A suspended request restores its state instead of re-prefilling.

  junctionBoundary() = kvBoundary > resumeBoundary() ? kvBoundary : 0;
};

Memory Plan & Governor

MemoryPlan

Input: ModelMemoryFootprint from the loaded model.

targetWeightsBytesactiveStateCellBytes sharedPrefillBytessharedDecodeBytes pipelineReserveBytesruntimeOverheadReserveBytes streamableWeightBytesstreamCacheBytes visionWeightsBytesdraftWeightsBytes

Output: a budget the governor enforces. fixedRuntimeBytes = weights + state + pipeline + overhead; remainder is the KV budget. Refuses to start if budget < required.

MemoryGovernor

Sole physical-memory admission ledger. Does not allocate, evict, or schedule; gives a short-lived "you may use N bytes" permit.

  • Pressure: Normal → Warning → Critical
  • Warning: available < reserve + margin → sheds cache in paced passes
  • Critical: available < reserve/2, or OS critical → drops every evictable entry
  • Hysteresis: growth stops at reserve+margin; recovery needs the larger margin
  • Bounded shrink passes separated by a telemetry settling interval
EngineConfig knobs: maxContext, vocabularySize, prefillCheckpointTokens (4096), maxImagePatches, prefillChunkTokens, resourceWaitTimeoutMilliseconds (30000). Live host pressure is supplied by the runtime governor and queried only on failed allocation, never on the hot path.
