One decode step, end to end

1

Draft

~7 ms

Draft head guesses up to 5 tokens (stops early when unsure). Each guess: its own attention layer + experts + 64K-token output layer.

2

Verify

~65 ms

Full model checks anchor + guesses in one pass. Per layer: router → pick experts → cached ones run on GPU while missing ones stream from SSD in "waves".

3

Accept

+1 token

Keep the guesses the model agrees with, plus one token of its own. Repeat.

≈ 2.8–3.1 tokens/step → ~38–40 tok/s on a 64 GB Mac

Dependency rules enforced by dev/tools/check_architecture.py

Model folders launch their own kernelsShared model code may not — model-specific GPU work stays in one place.
Models never depend on the engine…or on another model. Models stay swappable.
Shared ops/metal never depend on a modelShared code stays shared.
Engine never names a concrete modelExcept its startup files. Scheduling & memory policy work for any model.
Honest limit: the shared runtime assumes the Qwen hybrid family — linear + full attention layers, 8-bit paged KV cache, recurrent state per request. A model outside that family would need the runtime's buffers and state generalized. That work is not done yet.
